Техническое задание на разработку веб-приложения «Птичка»

1. Общие сведения
   1.1. Наименование системы: «Птичка» — рейтинговая платформа для учёта сдачи вторсырья.
   1.2. Назначение: мотивация населения к раздельному сбору отходов через прозрачную систему баллов и публичный рейтинг.
   1.3. Целевая аудитория: физические лица (участники) и администраторы пунктов приёма вторсырья.

2. Цели и задачи
   2.1. Обеспечить простую регистрацию пользователей с подтверждением номера телефона через SMS.
   2.2. Реализовать механизм начисления баллов за сданное вторсырьё на основе фиксированных коэффициентов.
   2.3. Предоставить публичный рейтинг участников (топ-10) без раскрытия персональных данных.
   2.4. Создать административную панель для внесения данных о сдаче и просмотра статистики.
   2.5. Отображать динамику сдачи вторсырья на графике (личная и средняя по всем участникам).
   2.6. Обеспечить возможность смены аватарки в личном профиле.
   2.7. Гарантировать защиту от накруток: баллы начисляются только подтверждённым пользователям; данные вносит администратор.

3. Функциональные требования
   3.1. Регистрация и аутентификация
        - Пользователь вводит номер телефона, ФИО и пароль.
        - После регистрации на указанный номер отправляется SMS с 6-значным кодом подтверждения.
        - До подтверждения номера аккаунт считается неактивным, баллы равны нулю.
        - Вход выполняется по номеру телефона и паролю.
        - Для отправки SMS используется сторонний API (TargetSMS); архитектура допускает смену провайдера (например, на МТС Exolve).
   3.2. Роли пользователей
        - Обычный пользователь (User):
            * просмотр публичного рейтинга (без чужих телефонов);
            * личный кабинет с историей сдач, баллами и местом в рейтинге;
            * загрузка аватарки (jpg, png) размером до 2 МБ.
        - Администратор (Admin):
            * добавление записей о сдаче вторсырья для любого подтверждённого пользователя;
            * просмотр списка всех пользователей с сортировкой;
            * просмотр детальной истории сдачи конкретного пользователя (отдельная страница);
            * доступ к админ-панели защищён декоратором @admin_required.
   3.3. Система баллов
        - Каждому типу материала задан коэффициент (см. Приложение А).
        - Баллы = вес сданного вторсырья (кг) × коэффициент.
        - Справочник материалов синхронизируется с БД при запуске приложения.
        - Баллы подсчитываются автоматически при внесении записи администратором.
   3.4. Рейтинг и аналитика
        - Публичный рейтинг отображает топ-10 подтверждённых пользователей (без администраторов).
        - На главной странице расположен график (Chart.js): личная динамика (кг/день) и средняя по всем участникам.
        - В личном кабинете пользователь видит своё место в общем рейтинге.
   3.5. Административная панель
        - Форма добавления сдачи: выбор пользователя, типа материала, веса (кг).
        - Таблица пользователей с сортировкой по столбцам и кнопками «История» и «Сдача».
        - История пользователя открывается на отдельной странице со сводкой и списком всех его сдач.
   3.6. Дополнительные возможности
        - Адаптивный интерфейс на Bootstrap 5 с анимациями.
        - Поддержка PWA (manifest.json, service worker) для установки на мобильные устройства.
        - Страницы ошибок (403, 404, 500) с пользовательским дизайном.

4. Нефункциональные требования
   4.1. Производительность: время отклика не более 2 секунд при стандартной нагрузке.
   4.2. Безопасность:
        - Пароли хранятся в виде хеша (Werkzeug pbkdf2:sha256).
        - Защита от CSRF (Flask-WTF).
        - Доступ к админ-функциям только после проверки роли.
   4.3. Масштабируемость: модульная структура позволяет заменять SMS-провайдера, тип БД, добавлять новые типы материалов без переписывания ядра.
   4.4. Кроссплатформенность: корректное отображение в актуальных версиях Chrome, Firefox, Safari, а также на мобильных устройствах.

5. Технологический стек
   5.1. Бэкенд: Python 3.9+, Flask, SQLAlchemy (ORM), SQLite.
   5.2. Фронтенд: Bootstrap 5, Chart.js, HTML/CSS/JavaScript.
   5.3. Аутентификация: Flask-Login, Werkzeug (хеширование).
   5.4. SMS-интеграция: requests → TargetSMS API (GET-запросы).
   5.5. Формы: WTForms + Flask-WTF.
   5.6. Загрузка файлов: Flask-Uploads (реализовано через стандартные средства Flask).
   5.7. PWA: Service Worker, Web App Manifest.
   5.8. Зависимости перечислены в requirements.txt.

6. Структура проекта
   app.py              – основной файл приложения
   config.py           – конфигурация
   models.py           – модели БД (User, Material, Submission)
   forms.py            – классы WTForms
   utils.py            – вспомогательные функции (SMS, синхронизация)
   coefficients.py     – словарь коэффициентов
   seed_data.py        – скрипт генерации тестовых данных
   requirements.txt    – зависимости
   templates/          – HTML-шаблоны (base, index, register, login, verify, profile, admin/…)
   static/             – CSS, JS, иконки, загруженные аватарки
