Описание проекта «Птичка»

«Птичка» — это веб-приложение, которое превращает сдачу вторсырья в 
соревнование с прозрачными правилами. Участники получают баллы за каждый 
килограмм сданного материала, а система автоматически рассчитывает их 
место в публичном рейтинге. Администраторы пунктов приёма вносят данные 
о сдаче через удобную панель, исключая ошибки ручного учёта.

Основная идея
--------------
Многие люди не сортируют отходы, потому что не видят личной выгоды и не 
понимают, как их действия влияют на экологию. «Птичка» решает эту 
проблему через:
- Понятную систему баллов, где каждый килограмм вторсырья имеет свой 
  «вес» в зависимости от сложности переработки (например, стекло — 
  1 балл/кг, а CD-диски — 15 баллов/кг).
- Публичный рейтинг, который показывает топ-10 участников без раскрытия 
  персональных данных (только имя и баллы).
- График динамики на главной странице, позволяющий сравнить личный вклад 
  со средним по сообществу.

Как это работает
----------------
1. Пользователь регистрируется по номеру телефона и подтверждает его 
   через SMS-код. Пока номер не подтверждён, баллы не начисляются — это 
   защищает рейтинг от накруток.
2. Администратор пункта приёма вносит запись о сдаче: выбирает участника, 
   тип материала и вес. Баллы рассчитываются автоматически.
3. Участник видит свои баллы, историю сдач и текущее место в рейтинге в 
   личном кабинете. Там же можно загрузить аватарку.
4. На главной странице отображается топ-10 участников и интерактивный 
   график с двумя линиями: «Мои сдачи» (голубая) и «Среднее по всем» 
   (красная).

Роли пользователей
-------------------
Обычный пользователь:
- Просмотр публичного рейтинга (без телефонов других участников).
- Личный кабинет с баллами, местом в рейтинге и историей сдач.
- Загрузка аватарки (jpg, png) размером до 2 МБ.
- График личной динамики на главной странице.

Администратор:
- Добавление записей о сдаче вторсырья для любого подтверждённого 
  пользователя.
- Просмотр списка всех пользователей с сортировкой по любому столбцу.
- Просмотр детальной истории сдачи конкретного пользователя (отдельная 
  страница).
- Доступ к админ-панели только после входа под учётной записью с правами 
  администратора.

Технические особенности
-----------------------
- Бэкенд на Python с фреймворком Flask и ORM SQLAlchemy.
- Хранение данных в SQLite (легко заменяется на PostgreSQL).
- Безопасная аутентификация: пароли хешируются Werkzeug, сессии 
  управляются Flask-Login.
- Подтверждение номера телефона через SMS (сервис TargetSMS). Архитектура 
  позволяет быстро переключиться на другого провайдера, например 
  МТС Exolve.
- Фронтенд на Bootstrap 5 с адаптивным дизайном и анимациями.
- График динамики на Chart.js с плавными линиями и временной шкалой.
- Поддержка PWA (Progressive Web App): сайт можно установить на телефон 
  как обычное приложение и пользоваться без доступа к интернету (после 
  первого открытия).
- Загрузка файлов (аватарок) с проверкой формата и размера.
- Защита от накруток: баллы получают только пользователи с подтверждённым 
  номером телефона; администраторы исключены из рейтинга; вносить записи 
  может только администратор.
- Готовый скрипт для наполнения базы тестовыми данными (100 пользователей 
  с историей за 30 дней).

Структура проекта
-----------------
app.py              – маршруты, логика обработки запросов
config.py           – настройки (секретный ключ, SMS, БД)
models.py           – модели базы данных (User, Material, Submission)
forms.py            – классы для валидации форм (WTForms)
utils.py            – вспомогательные функции (SMS, синхронизация)
coefficients.py     – словарь коэффициентов для материалов
seed_data.py        – скрипт генерации тестовых данных
requirements.txt    – список зависимостей
templates/          – HTML-шаблоны страниц
static/             – CSS, JavaScript, иконки, загруженные аватарки

Применённые технологии
-----------------------
- Flask, SQLAlchemy, SQLite – серверная часть и работа с данными.
- Flask-Login, Werkzeug – аутентификация и безопасность.
- WTForms, Flask-WTF – обработка форм.
- TargetSMS API – отправка SMS-кодов подтверждения.
- Bootstrap 5 – адаптивная вёрстка интерфейса.
- Chart.js – интерактивные графики.
- JavaScript (чистый) – сортировка таблиц на клиенте.
- PWA (Manifest, Service Worker) – офлайн-доступ и установка на телефон.
- Python-dotenv – загрузка конфигурации из .env файла.

Как запустить
-------------
1. Установить зависимости: pip install -r requirements.txt
2. Настроить .env файл (см. пример ниже).
3. Запустить приложение: python app.py
4. Открыть в браузере: http://127.0.0.1:5000
5. Для наполнения тестовыми данными: python seed_data.py
   (предварительно остановить Flask)

Пример .env файла:
SECRET_KEY=ваш_секретный_ключ
TARGETSMS_USER=логин_в_targetsms
TARGETSMS_PWD=пароль_в_targetsms
TARGETSMS_SENDER=targettele
SMS_TEST_MODE=False (или True для вывода кода в консоль)

Возможности для развития
------------------------
- Подключение профессиональных SMS-провайдеров (МТС Exolve).
- Переход на PostgreSQL или MySQL для высокой нагрузки.
- Мобильное приложение на React Native или Flutter.
- Интеграция с весами в пунктах приёма для автоматического ввода данных.
- Достижения и значки за определённые объёмы сдачи.
- Расширенная аналитика по регионам и типам материалов.
